# Kawaii 1 Year Anniversary Website 💖

## What to do tonight

1. Open this folder in VS Code.
2. Replace the placeholder files inside:
   `assets/photos/`

   Use these filenames:
   - photo1.jpg
   - photo2.jpg
   - photo3.jpg
   - photo4.jpg
   - photo5.jpg
   - photo6.jpg

3. Open `script.js`.
4. Edit:
   - `memories`
   - `letters`
5. Open `index.html`.
6. Edit the final message if you want.

## Test it

Double-click `index.html`.

## Put it online with GitHub Pages

1. Make a new GitHub repo.
2. Upload all files from this folder.
3. Go to repo Settings.
4. Go to Pages.
5. Source: Deploy from branch.
6. Branch: main / root.
7. Save.
8. Send her the GitHub Pages link.

## Optional music

Add a file called `music.mp3` inside `assets`.
Then in `index.html`, uncomment the audio source line.
Most phones block autoplay, so music is optional.
